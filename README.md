# Power Wards

Power Wards 是一款 Dota 2 侦察守卫眼位地图编辑器。它帮助你把零散的眼位经验整理在地图上：标出位置，写下插眼方法和适用时机，再按阵营、用途或标签查找，也可以把自己的眼位资料分享给朋友。

你可以为不同打法或来源建立独立资料，从自己的实战经验开始，也可以导入朋友分享的资料继续完善。

## 主要功能

- **在地图上记录眼位**：为每个眼位添加名称、详细说明、颜色和游戏截图；支持重新定位、删除及撤销删除。
- **分类与筛选**：按天辉或夜魇、进攻或防守，以及自定义标签查找眼位；一个眼位可以属于多个分类。
- **管理多份资料**：创建、切换、重命名和另存为 Profile，分别整理不同打法或来源的眼位。
- **导入与分享**：通过 JSON 文件交换眼位位置、分类、标签和文字说明。导入会创建独立副本，不会覆盖已有资料。

## 开始使用

桌面版可从 [Releases 页面](https://github.com/HuangLA/power-wards/releases) 获取。想在本机运行网页端或参与开发，请查看 [开发与运行说明](app/README.md)。

1. 在左侧新建一个 Profile，或导入已有的眼位资料。
2. 按住 **Ctrl 并左键点击地图**，或点击「添加眼位」后选择位置，再设置适用分类。
3. 点击眼位，在右侧补充说明、标签和截图。需要调整位置时使用「重新定位」。
4. 点击顶部「保存」。你也可以「另存为」保留原资料，再编辑新的副本。
5. 使用左侧筛选快速查找眼位；需要分享时点击「导出」。

地图支持滚轮缩放、按住左键拖动平移，右键可恢复全图。点击已有眼位会聚焦并打开详情。

## 保存与分享

修改需要手动保存；未保存时，应用会在切换资料或关闭前提醒你。导出也会先要求保存当前修改。

分享用的 JSON 包含眼位和文字资料，**不包含截图**。如果希望对方看到截图，需要另外发送图片。导入不同地图版本的资料时，眼位位置可能出现偏移，请在地图上核对。
