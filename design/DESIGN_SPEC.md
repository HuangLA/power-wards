# Power Wards · 设计说明与 Agent 交接

## 交付状态

交付为本地 Figma 开发插件生成包，用户需在 Figma 中导入并运行才能得到原生可编辑设计页。未创建云端文件，未验证真实 Figma 渲染，未恢复应用实现。`REQUIREMENTS.md` 是业务规则真源。

## 视觉方向

沿用已认可概念图：深灰背景、琥珀主操作，青蓝与珊瑚眼位，轻边框，紧凑三栏。1600×1000 为桌面设计基准；顶栏高 64；选中状态左右中宽度分别为 288 / 960 / 352（18% / 60% / 22%）。未选中时隐藏右侧详情，地图容器扩展。这是布局提案，不代表已确认响应式规则。

颜色、字号、间距与圆角见 `tokens.json`。正文 14px、说明 12px、区块标题 16px、详情标题 22px。图片以外均为原生文本与矢量节点；按钮、分类、标签、Profile 选择器使用自动布局组件。屏幕和地图覆盖层保留固定基准坐标，供后续响应式设计调整。

## 状态与规则映射

| 状态 | 设计重点 |
| --- | --- |
| 浏览 | 当前 Profile 选择、分类和标签筛选；无选中详情 |
| 选中详情 | 立即聚焦的视觉示意、本地截图置顶、颜色与四种分类、标签、详细说明 |
| 新增 | 底部面板独立多选天辉进攻/天辉防守/夜魇进攻/夜魇防守 |
| Profile 管理 | 单 Profile 展示；自己的、朋友和职业选手资料都是可编辑本地副本 |
| 未保存确认 | 应用内切换/桌面关闭的保存、放弃修改、取消三选项 |

右栏示例同时选「天辉进攻」和「夜魇防守」，不得推导另两种组合。标签 AND/OR 尚未明确；设计中的选中样式不定义筛选逻辑。颜色独立于分类。

保存更新当前 Profile，另存为创建新 Profile、保留原保存版本。JSON 分享所有约定文本（包括详细说明）、位置、颜色、分类、标签和必要元数据，不含截图；接收者自行上传。顶部未保存标识不代表自动保存。

Ctrl + 左键新增；点眼位选中并聚焦；滚轮缩放；左键拖动平移；右键全图。双击新增未启用。示意放大不定义实际倍率。移动/删除/撤销不在此设计中冒充已确认功能。

网页关闭无法承诺自定义三按钮或异步保存；05 是应用内导航及桌面语义，浏览器关闭应另按平台能力设计。无账号、在线分享链接、多人协作或云同步。

## 原生图层与组件

每次生成一个新页，包含 00–06 命名 Frame。组件集使用 `PW/` 前缀和明确 State/Tone 变体。实例保留关联；修改主组件可传播，文案可在实例内覆盖。文本/颜色样式以生成时间戳分组，避免覆盖其他设计样式；token JSON 是源码侧的统一值来源。

颜色样式和文字样式创建为可复用本地样式；生成器当前直接设置节点属性，不将所有节点绑定到样式。自动布局主要用于组件内部，屏幕几何为固定基准设计。无交互原型连线。这些限制应在后续设计迭代中据需要补齐。

AI agent 应按 `Header / Save actions`、`Sidebar / Current profile & filters`、`Map / Relative-coordinate overlay`、`Inspector / Selected ward`、`Overlay / New ward classification` 等名称获取上下文，不依赖不存在的固定 node ID。标记包含 `relativeCoordinate` pluginData，但眼位均为虚构设计点位，不可当作实战攻略数据。

## 检查与后续验收

本地检查包含 JavaScript 语法、JSON 解析、资源存在及嵌入一致性，以及受限模拟器中的五屏、组件集、实例、中文文本、图片填充和既有页隔离。它不能替代真实 Figma 运行。

用户导入后需检查：中文字形无缺字；长文字不溢出；五个状态均生成；地图比例与局部示意标识正确；组件实例可编辑；未覆盖已有页。完成后可提供实际 Frame 链接供 AI agent 接续。设计不表示应用功能已完成。
