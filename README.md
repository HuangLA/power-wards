# Power Wards · 眼位地图编辑器

Power Wards 是一个 Dota 2 侦察守卫眼位整理工具。你可以在地图上标记眼位，记录阵营与进攻/防守用途、标签、操作说明和本地游戏截图，再把文字与点位导出为 JSON 分享给别人。当前地图版本为 7.41，应用提供 Windows 桌面端和需要本机 Node 服务的网页端。

项目目前面向单机使用，没有账号、云同步或在线分享。桌面端与网页端的本地资料各自保存，互不自动同步；需要交换资料时使用导出和导入。项目不预置真实攻略眼位，截图和说明由使用者自行添加。

## 下载与启动

Windows x64 用户从本项目的 GitHub Releases 下载 `Power-Wards-v0.1.0-win-x64.zip`，**完整解压**后运行其中的 `Power Wards.exe`。这是便携版，不需要安装；目前未做数字签名，Windows 可能显示“未知发布者”。请保留解压目录内的所有文件，不要单独移动 EXE。

如果要从源码运行网页端，请安装 Node.js 和 npm，在 `app/` 目录运行：

```bash
npm install
npm run dev
```

然后打开 `http://localhost:5173`。`npm run dev` 会同时启动网页与本机文件服务，关闭终端后服务也会停止。只打开静态 HTML 或单独运行 Vite 预览，无法保存本机资料。开发、构建及验证命令见 [app/README.md](app/README.md)。

## 开始整理眼位

1. 在左侧 **Profile** 区选择当前资料，或点「新建」创建一个 Profile。地图一次只显示一个 Profile。左侧也可以重命名、删除或导入 Profile。
2. 在地图上按住 **Ctrl 并左键点击**想标记的位置，或者先点「＋ 添加眼位」再点击地图。下方出现分类面板后，选择适用的组合并确认。四种组合为「天辉进攻」「天辉防守」「夜魇进攻」「夜魇防守」，同一眼位可以选多个。
3. 点击地图上的眼位，在右侧填写名称、详细说明、颜色和自定义标签；需要时上传自己的游戏截图。截图支持 PNG、JPEG、WebP，每张不超过 8 MiB、每个眼位最多 10 张。
4. 修改后顶部会显示「未保存」。点「保存」更新当前 Profile；点「另存为」创建新副本并保留原 Profile 的已保存版本。应用不会自动保存编辑内容。

地图操作：滚轮缩放、按住左键拖动平移、右键恢复全图。点击眼位会选中并聚焦。右侧「重新定位」后，点击地图上的新位置即可移动眼位；按 Esc 可退出定位。删除眼位后，页面会在 8 秒内提供撤销入口，撤销会恢复该眼位及其关联资料。

## 查找、分享与导入

左侧筛选可分别选择天辉/夜魇、进攻/防守和自定义标签。初始显示全部符合条件的眼位；点击某个标签后只显示带该标签的眼位，继续点击可按任一所选标签匹配。某一组筛选项全部取消时，地图不显示眼位。点击底部「全选筛选项」可恢复初始筛选状态。

点顶部「导出」可生成分享用 JSON。**导出前必须先保存当前修改**：若有未保存内容，应用会提示保存或另存为；取消或保存失败就不会导出。JSON 包含点位、分类、标签和文字说明，**不包含截图**。需要分享截图时，请另行传送图片。

收到别人的 JSON 后，点左侧「导入」。每次导入都会创建独立的本地 Profile；同名资料自动添加后缀，不覆盖原资料。地图版本不同也可以导入，但眼位位置可能偏移，请自行核对。

## 资料保存与备份

Profile 和截图保存在本机文件中，而非仅存在浏览器缓存。清理浏览器数据不会删除已经保存到本机文件服务的资料。桌面端和网页端使用不同的默认资料目录；具体位置、自定义目录方法及旧版网页资料迁移说明见 [app/README.md](app/README.md)。

未点「保存」或「另存为」的修改不会写入资料文件。关闭或切换 Profile 时，桌面端会提示保存、放弃修改或取消；网页关闭或刷新时使用浏览器原生未保存警告。建议定期备份本机数据目录；导出的 JSON 不能替代截图备份。
